## ✨ لماذا MiniCal؟

### 🎯 دائماً في متناول يدك، لن يزعجك أبداً

**المشكلة**: تستغرق تطبيقات التقويم التقليدية أكثر من 5 ثوانٍ للفتح. إذا كنت تتحقق من التقويم أكثر من 20 مرة يومياً، فأنت تهدر **8 ساعات** سنوياً.

**الحل**: يبقى MiniCal في شريط القوائم. نقرة واحدة، 0.3 ثانية فقط.

- 🖱️ **تمرير الماوس**: حرك الماوس على الأيقونة، يفتح التقويم تلقائياً
- ⌨️ **اختصار عام**: اضغط `⌥⌘C` من أي تطبيق للفتح الفوري
- 📍 **لا يشغل مساحة**: يبقى في شريط القوائم، لا يشغل مساحة في Dock
- ⚡ **استجابة فائقة السرعة**: استخدام ذاكرة <50MB، استخدام CPU <1%

> **تقييم المستخدمين**: _"أتحقق من التقويم 20 مرة يومياً. MiniCal وفر لي 8 ساعات سنوياً!"_ - John، مهندس برمجيات

### 🌊 تصميم Liquid Glass - المستقبل هنا الآن

أول تطبيق تقويم يتبنى لغة تصميم **macOS Liquid Glass**.

- ✨ **مادة زجاجية سائلة**: زجاج شبه شفاف ديناميكي، يتكيف تلقائياً مع سمة النظام
- 🎨 **ألوان بعمق**: نظام ألوان العمق iOS 16+
- 🔮 **رسوم متحركة 120fps**: سلسة كالحرير (محسّن لـ M1+)
- 🌓 **وضع داكن مثالي**: تبديل سلس بين الوضع الفاتح/الداكن

**بينما لا تزال تطبيقات التقويم الأخرى عالقة في تصميم 2020، احتضن MiniCal بالفعل مستقبل تصميم Apple لعام 2024.**

## 💻 النظرة التقنية

### البنية

**النمط**: MVVM (Model-View-ViewModel)

```
┌─────────────────┐
│  MenuBarView    │  ← طبقة SwiftUI (طبقة العرض)
│  CalendarView   │
│  SettingsView   │
└────────┬────────┘
         │ @ObservedObject / @Published
         ↓
┌─────────────────┐
│ CalendarViewModel    │  ← نموذج العرض (منطق الأعمال)
│ MenuBarViewModel     │
│ EventListViewModel   │
└────────┬─────────────┘
         │ استدعاء الخدمات
         ↓
┌─────────────────┐
│ CalendarService      │  ← طبقة الخدمات (معالجة البيانات)
│ EventService         │
│ ThemeManager         │
│ SettingsManager      │
└────────┬─────────────┘
         │ عمليات النموذج
         ↓
┌─────────────────┐
│ CalendarEvent        │  ← نموذج البيانات
│ CalendarDate         │
│ UserSettings         │
└──────────────────────┘
```

## 🛠️ البناء من المصدر

### المتطلبات الأساسية

- Xcode 15.0+
- macOS 11.0+
- Swift 5.9+

### خطوات البناء

```bash
# 1. استنساخ المستودع
git clone https://github.com/minical/minical.git
cd minical

# 2. فتح مشروع Xcode
open MiniCal.xcodeproj

# 3. اختر MiniCal scheme

# 4. بناء (⌘B) أو تشغيل (⌘R)
```

### تكوين البناء

**بناء Debug**:
```bash
xcodebuild -project MiniCal.xcodeproj \
  -scheme MiniCal \
  -configuration Debug \
  build
```

**بناء Release**:
```bash
xcodebuild -project MiniCal.xcodeproj \
  -scheme MiniCal \
  -configuration Release \
  build
```

**موقع مخرجات البناء**:
```
~/Library/Developer/Xcode/DerivedData/MiniCal-*/Build/Products/Debug/MiniCal.app
```

### التحقق من التوطين

```bash
cd ~/Library/Developer/Xcode/DerivedData/MiniCal-*/Build/Products/Debug/MiniCal.app/Contents/Resources

# يجب أن ترى 13 مجلد .lproj
ls -la *.lproj/

# تحقق من وجود Info.plist في كل مجلد
ls -la *.lproj/Info.plist
```

## ❓ الأسئلة الشائعة

<details>
<summary><strong>لماذا تطبيق تقويم آخر؟</strong></summary>

التطبيقات الحالية إما تفتقر إلى دعم تقويمات متعددة، أو تصميمها قديم. يجمع MiniCal بين:
- ✅ تصميم Liquid Glass حديث
- ✅ دعم حقيقي لتقويمات متعددة الثقافات (7 أنظمة)
- ✅ نهج يعطي الأولوية للخصوصية (تخزين محلي)
- ✅ أداء مثالي (<50MB RAM)
- ✅ شفافية مفتوحة المصدر

</details>

<details>
<summary><strong>هل هو مجاني؟</strong></summary>

**الإصدار المجاني**: تقويم أساسي، نظام تقويم فرعي واحد
**الإصدار الاحترافي**: $19.99 شراء لمرة واحدة (جميع الميزات، تحديثات مدى الحياة)

أرخص بكثير من Fantastical ($56.99/سنة) أو Calendars 5 ($39.99/سنة).

</details>

<details>
<summary><strong>هل يمكن المزامنة عبر الأجهزة؟</strong></summary>

v1.0 يستخدم التخزين المحلي فقط (الخصوصية أولاً). مزامنة iCloud مخططة لـ v1.1 (اختياري).

تقويم النظام الخاص بك (iCloud، Google، Exchange) يتم مزامنته بالفعل من خلال تكامل تقويم macOS.

</details>

<details>
<summary><strong>كيف يتم حماية الخصوصية؟</strong></summary>

- ✅ 100% تخزين بيانات محلي
- ✅ لا حساب، لا تسجيل دخول
- ✅ لا تحليلات، لا تتبع
- ✅ كود مفتوح المصدر (قابل للمراجعة)
- ✅ يعمل دون اتصال بالكامل

</details>

<details>
<summary><strong>هل يمكن تخصيص المظهر؟</strong></summary>

نعم! يوفر MiniCal:
- أكثر من 10 سمات مدمجة
- سمات JSON مخصصة (أكثر من 20 معامل لون)
- تخصيص التخطيط (الحجم، يوم بداية الأسبوع، الكثافة)
- تبديل الوحدات (اختيار ما يتم عرضه)

انظر [دليل السمات](THEMES.md) للتفاصيل.

</details>

<details>
<summary><strong>ما هي أنظمة التقويم المدعومة؟</strong></summary>

1. الميلادي (عالمي)
2. القمري (الصين - 1.4 مليار مستخدم)
3. الهجري (Hijri - 1.9 مليار مستخدم)
4. العبري (اليهودي - 15 مليون مستخدم)
5. الفارسي (Jalali - 120 مليون مستخدم)
6. الياباني (عصر ريوا - 120 مليون مستخدم)
7. البوذي (500 مليون مستخدم)

كل منها له محرك حساب أصلي وخصائص ثقافية.

</details>

## 🏆 المقارنة

### MiniCal vs Fantastical vs BusyCal

| الميزة | MiniCal | Fantastical | BusyCal |
|------|---------|-------------|---------|
| **أنظمة التقويم** | ✅ 7 | ⚠️ 2 | ❌ 1 |
| **اللغات** | ✅ 13 | ⚠️ 7 | ⚠️ 5 |
| **التصميم** | ✅ Liquid Glass 2024 | ⚠️ iOS 14 | ❌ تقليدي |
| **الفلك** | ✅ احترافي | ⚠️ أساسي | ❌ لا يوجد |
| **الخصوصية** | ✅ محلي أولاً | ❌ سحابي أولاً | ⚠️ اختياري |
| **الأداء** | ✅ <50MB RAM | ⚠️ ~80MB | ⚠️ ~100MB |
| **السعر** | 💰 $19.99 (شراء) | 💰💰 $56.99/سنة | 💰 $49.99 (شراء) |
| **تكلفة 5 سنوات** | **$19.99** | **$284.95** | **$49.99** |
| **مفتوح المصدر** | ✅ نعم | ❌ لا | ❌ لا |

## 💰 التسعير

**الإصدار المجاني**:
- تقويم شريط القوائم
- ميلادي + تقويم فرعي واحد
- لغتان
- 3 سمات
- تكامل تقويم النظام

**الإصدار الاحترافي** ($19.99):
- جميع أنظمة التقويم السبعة
- جميع اللغات الـ 13
- سمات غير محدودة + سمات مخصصة
- اشتراكات خارجية
- ميزات فلكية
- تحديثات مدى الحياة
- دعم الأولوية

**خصم تعليمي** ($14.99):
- يتطلب تحقق من بريد .edu

**ترخيص فريق** (10 أشخاص فأكثر):
- $12.99/شخص
- خصم كمية
