## ✨ 為什麼選擇 MiniCal？

### 🎯 隨時可達，絕不礙事

**痛點**：傳統行事曆應用程式開啟需要 5 秒以上。你每天查看行事曆 20+ 次，每年浪費 **8 小時**。

**解決方案**：MiniCal 常駐選單列。一次點擊，0.3 秒即達。

- 🖱️ **滑鼠懸停**：滑鼠移到圖示，行事曆自動展開
- ⌨️ **全域快速鍵**：任何應用程式下按 `⌥⌘C` 秒開
- 📍 **不佔空間**：選單列常駐,不佔用 Dock 位置
- ⚡ **極速回應**：<50MB 記憶體，<1% CPU

> **使用者評價**：_「我每天查看行事曆 20 次，MiniCal 每年為我節省 8 小時！」_ - John，軟體工程師

---

### 🌊 Liquid Glass 設計 - 未來已來

首款採用 **macOS Liquid Glass** 設計語言的行事曆應用。

- ✨ **流體玻璃材質**：動態半透明毛玻璃，自適應系統主題
- 🎨 **景深色彩**：iOS 16+ 景深色彩系統
- 🔮 **120fps 動畫**：絲滑流暢（M1+ 最佳化）
- 🌓 **完美深色模式**：淺色/深色無縫切換

**當其他行事曆應用還停留在 2020 年的設計時，MiniCal 已經擁抱了 Apple 2024 年的設計未來。**

## 💻 技術概覽

### 架構

**模式**：MVVM（Model-View-ViewModel）

```
┌─────────────────┐
│  MenuBarView    │  ← SwiftUI 視圖（展示層）
│  CalendarView   │
│  SettingsView   │
└────────┬────────┘
         │ @ObservedObject / @Published
         ↓
┌─────────────────┐
│ CalendarViewModel    │  ← 視圖模型（業務邏輯）
│ MenuBarViewModel     │
│ EventListViewModel   │
└────────┬─────────────┘
         │ 服務呼叫
         ↓
┌─────────────────┐
│ CalendarService      │  ← 服務層（資料處理）
│ EventService         │
│ ThemeManager         │
│ SettingsManager      │
└────────┬─────────────┘
         │ 模型操作
         ↓
┌─────────────────┐
│ CalendarEvent        │  ← 資料模型
│ CalendarDate         │
│ UserSettings         │
└──────────────────────┘
```

### 技術堆疊

**語言與框架**：
- Swift 5.9+
- SwiftUI（UI 框架）
- AppKit（NSStatusBar、NSPopover 整合）
- EventKit（系統行事曆存取）
- CoreLocation（天文計算）

**外部相依**（Swift Package Manager）：
- [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts) @ 2.4.0 - 全域快速鍵

**資料持久化**：
- UserDefaults（設定）

**本地化**：
- Xcode String Catalogs（.xcstrings 格式）
- 每種語言獨立的完整 Info.plist（非 InfoPlist.strings）
- RTL 版面支援（View+RTL.swift）

## 📦 安裝

### 系統需求

- macOS 11.0（Big Sur）或更高版本
- Apple Silicon（M1/M2/M3）或 Intel Mac

### 下載

**方式 1：Mac App Store**（推薦）
```
即將上線...
```

**方式 2：直接下載**
```
下載地址：https://minical.app/download
```

**方式 3：從原始碼建置**

```bash
# 複製儲存庫
git clone https://github.com/aireels-dev/mini-cal.git
cd minical

# 在 Xcode 中開啟
open MiniCal.xcodeproj

# 按 ⌘R 建置並執行
```

### 首次啟動

1. **授予權限**（可選）：
   - 行事曆存取：顯示你的事件
   - 定位存取：日出日落、禮拜時間

2. **設定**：
   - 右鍵點擊選單列圖示 → 設定
   - 選擇你偏好的曆法系統、主題、語言

3. **開始使用**：
   - 點擊選單列圖示或按 `⌥⌘C`
   - 用箭頭導覽月份
   - 點擊日期查看事件

## 🛠️ 從原始碼建置

### 前置需求

- Xcode 15.0+
- macOS 11.0+
- Swift 5.9+

### 建置步驟

```bash
# 1. 複製儲存庫
git clone https://github.com/aireels-dev/mini-cal.git
cd minical

# 2. 開啟 Xcode 專案
open MiniCal.xcodeproj

# 3. 選擇 MiniCal scheme

# 4. 建置（⌘B）或執行（⌘R）
```

### 建置設定

**Debug 建置**：
```bash
xcodebuild -project MiniCal.xcodeproj \
  -scheme MiniCal \
  -configuration Debug \
  build
```

**Release 建置**：
```bash
xcodebuild -project MiniCal.xcodeproj \
  -scheme MiniCal \
  -configuration Release \
  build
```

**建置產物位置**：
```
~/Library/Developer/Xcode/DerivedData/MiniCal-*/Build/Products/Debug/MiniCal.app
```

### 驗證本地化

```bash
cd ~/Library/Developer/Xcode/DerivedData/MiniCal-*/Build/Products/Debug/MiniCal.app/Contents/Resources

# 應該看到 13 個 .lproj 資料夾
ls -la *.lproj/

# 驗證每個資料夾中都有 Info.plist
ls -la *.lproj/Info.plist
```

## ❓ 常見問題

<details>
<summary><strong>為什麼又要一個行事曆應用？</strong></summary>

現有應用要麼缺乏多曆法支援，要麼設計過時。MiniCal 結合了：
- ✅ 現代 Liquid Glass 設計
- ✅ 真正的多文化曆法支援（7 種系統）
- ✅ 隱私優先方案（本機儲存）
- ✅ 極致效能（<50MB RAM）
- ✅ 開源透明

</details>

<details>
<summary><strong>免費嗎？</strong></summary>

**免費版**：基礎行事曆，1 個副曆系統
**專業版**：$19.99 一次性購買（所有功能，終身更新）

比 Fantastical（$56.99/年）或 Calendars 5（$39.99/年）便宜得多。

</details>

<details>
<summary><strong>能跨裝置同步嗎？</strong></summary>

v1.0 僅使用本機儲存（隱私優先）。iCloud 同步計畫在 v1.1 推出（可選）。

你的系統行事曆（iCloud、Google、Exchange）已透過 macOS 行事曆整合實現同步。

</details>

<details>
<summary><strong>如何保護隱私？</strong></summary>

- ✅ 100% 本機資料儲存
- ✅ 無需帳號，無需登入
- ✅ 無分析，無追蹤
- ✅ 開源程式碼（可稽核）
- ✅ 完全離線執行

</details>

<details>
<summary><strong>可以自訂外觀嗎？</strong></summary>

可以！MiniCal 提供：
- 10+ 內建主題
- 基於 JSON 的自訂主題（20+ 顏色參數）
- 版面自訂（尺寸、週起始日、密度）
- 模組切換（選擇顯示什麼）

詳見[主題指南](THEMES.md)。

</details>

<details>
<summary><strong>支援哪些曆法系統？</strong></summary>

1. 公曆（全球通用）
2. 農曆（中國 - 14 億使用者）
3. 伊斯蘭曆（Hijri - 19 億使用者）
4. 希伯來曆（猶太 - 1500 萬使用者）
5. 波斯曆（Jalali - 1.2 億使用者）
6. 日本曆（令和紀年 - 1.2 億使用者）
7. 佛曆（5 億使用者）

每種都有原生計算引擎和文化特性。

</details>
