## ✨ MiniCal을 선택하는 이유

### 🎯 언제나 접근 가능, 방해하지 않음

**문제점**: 기존 캘린더 앱은 실행하는 데 5초 이상 걸립니다. 하루에 20번 이상 캘린더를 확인하면 연간 **8시간**을 낭비하게 됩니다.

**해결책**: MiniCal은 메뉴바에 상주합니다. 한 번의 클릭으로 0.3초 만에 접근.

- 🖱️ **마우스 호버**: 아이콘에 마우스를 올리기만 하면 캘린더가 자동으로 펼쳐집니다
- ⌨️ **글로벌 단축키**: 어떤 앱에서든 `⌥⌘C`를 누르면 즉시 열립니다
- 📍 **공간 절약**: 메뉴바에 상주하며 Dock 공간을 차지하지 않습니다
- ⚡ **초고속 응답**: 메모리 사용량 <50MB, CPU 사용률 <1%

> **사용자 평가**: _"매일 캘린더를 20번 확인합니다. MiniCal 덕분에 연간 8시간을 절약했어요!"_ - John, 소프트웨어 엔지니어

---

### 🌊 Liquid Glass 디자인 - 미래가 여기에

**macOS Liquid Glass** 디자인 언어를 채택한 최초의 캘린더 앱.

- ✨ **유체 유리 소재**: 동적 반투명 프로스트 글래스, 시스템 테마에 자동 적응
- 🎨 **깊이감 있는 색상**: iOS 16+ 깊이감 색상 시스템
- 🔮 **120fps 애니메이션**: 실크처럼 부드러움 (M1+ 최적화)
- 🌓 **완벽한 다크 모드**: 라이트/다크 모드 원활한 전환

**다른 캘린더 앱들이 2020년 디자인에 머물러 있는 동안, MiniCal은 이미 Apple 2024년 디자인의 미래를 받아들였습니다.**

### 🌍 세계의 역법을 하나의 화면에

**단순한 번역이 아닌 - 진정한 문화적 통합.**

| 역법 시스템 | 사용자층 | 고유 기능 |
|---------|---------|---------|
| 🇨🇳 **음력** | 14억 중화권 | 천간지지, 띠, 24절기, 전통 명절 |
| 🕌 **이슬람력** | 19억 무슬림 | 하루 5번 기도 시간, 라마단 알림 |
| 🕍 **히브리력** | 1,500만 유대인 | 안식일 시간, 유대교 명절 |
| 🇮🇷 **페르시아력** | 1.2억 사용자 | 노루즈, 정확한 춘분 계산 |
| 🇯🇵 **일본력** | 1.2억 사용자 | 레이와 연호, 일본 전통 명절 |
| 🙏 **불교력** | 5억 사용자 | 불교 명절, 팔관재일 |
| 🌏 **양력** | 전 세계 공통 | 100개 이상 국가 공휴일 |

**13개 언어 지원** (RTL 4개 포함): ar, en, fa, he, ja, ko, th, tr, ur, vi, zh-Hans, zh-Hant

> **전 세계 40억 이상의 사람들에게 서비스 제공** - 모든 문화의 시간은 존중받을 가치가 있기 때문입니다.

### 🌅 전문가 수준의 천문 계산

단순한 캘린더가 아닌 - 당신의 포켓 천문대.

- ☀️ **일출·일몰**: ±1분 정확도 (Solar 라이브러리 기반)
- 🌙 **달 모양**: 초승달, 보름달 자동 표시
- 🍂 **24절기**: 분 단위 정확도 (중국 전통 역법)
- 🕌 **이슬람 기도 시간**: 30가지 이상 계산 방법 (Adhan 라이브러리 기반)
- 🕍 **히브리 안식일**: 일몰 시간 자동 표시

**최적의 용도**:
- 📸 사진작가: 골든 아워 도우미
- 🕌 무슬림: 기도 시간 알림
- 🔭 천문 애호가: 관측 계획 도구

## 💻 기술 개요

### 아키텍처

**패턴**: MVVM (Model-View-ViewModel)

```
┌─────────────────┐
│  MenuBarView    │  ← SwiftUI 뷰 (프레젠테이션 레이어)
│  CalendarView   │
│  SettingsView   │
└────────┬────────┘
         │ @ObservedObject / @Published
         ↓
┌─────────────────┐
│ CalendarViewModel    │  ← 뷰 모델 (비즈니스 로직)
│ MenuBarViewModel     │
│ EventListViewModel   │
└────────┬─────────────┘
         │ 서비스 호출
         ↓
┌─────────────────┐
│ CalendarService      │  ← 서비스 레이어 (데이터 처리)
│ EventService         │
│ ThemeManager         │
│ SettingsManager      │
└────────┬─────────────┘
         │ 모델 조작
         ↓
┌─────────────────┐
│ CalendarEvent        │  ← 데이터 모델
│ CalendarDate         │
│ UserSettings         │
└──────────────────────┘
```

### 기술 스택

**언어 및 프레임워크**:
- Swift 5.9+
- SwiftUI (UI 프레임워크)
- AppKit (NSStatusBar, NSPopover 통합)
- EventKit (시스템 캘린더 액세스)
- CoreLocation (천문 계산)

**외부 의존성** (Swift Package Manager):
- [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts) @ 2.4.0 - 글로벌 단축키
- [Solar](https://github.com/ceeK/Solar) @ 3.0.1 - 일출·일몰 계산
- [Adhan](https://github.com/batoulapps/adhan-swift) @ 1.4.0 - 이슬람 기도 시간
- [LunarSwift](https://github.com/6tail/lunar-swift) @ 1.1.8 - 음력 계산

**데이터 지속성**:
- UserDefaults (설정)
- NSCache (이벤트 캐시)
- 로컬 파일 저장소 (구독, 테마)

**로컬라이제이션**:
- Xcode String Catalogs (.xcstrings 형식)
- 각 언어별 독립적인 완전한 Info.plist (InfoPlist.strings가 아님)
- RTL 레이아웃 지원 (View+RTL.swift)

### 첫 실행

1. **권한 부여** (선택사항):
   - 캘린더 액세스: 이벤트 표시
   - 위치 액세스: 일출·일몰, 기도 시간

2. **설정**:
   - 메뉴바 아이콘 우클릭 → 설정
   - 선호하는 역법 시스템, 테마, 언어 선택

3. **사용 시작**:
   - 메뉴바 아이콘 클릭 또는 `⌥⌘C` 누름
   - 화살표로 월 탐색
   - 날짜 클릭하여 이벤트 보기

## ❓ 자주 묻는 질문

<details>
<summary><strong>왜 또 다른 캘린더 앱이 필요한가요?</strong></summary>

기존 앱은 다중 역법 지원이 부족하거나 디자인이 구식입니다. MiniCal은 다음을 결합합니다:
- ✅ 현대적인 Liquid Glass 디자인
- ✅ 진정한 다문화 역법 지원 (7가지 시스템)
- ✅ 프라이버시 우선 접근 (로컬 저장소)
- ✅ 최고의 성능 (<50MB RAM)
- ✅ 오픈소스 투명성

</details>

<details>
<summary><strong>무료인가요?</strong></summary>

**무료 버전**: 기본 캘린더, 1개 부가력 시스템
**프로 버전**: $19.99 일회성 구매 (모든 기능, 평생 업데이트)

Fantastical ($56.99/년) 또는 Calendars 5 ($39.99/년)보다 훨씬 저렴합니다.

</details>

<details>
<summary><strong>기기 간 동기화가 가능한가요?</strong></summary>

v1.0은 로컬 저장소만 사용합니다 (프라이버시 우선). iCloud 동기화는 v1.1에서 계획되어 있습니다 (선택사항).

시스템 캘린더 (iCloud, Google, Exchange)는 macOS 캘린더 통합을 통해 이미 동기화됩니다.

</details>

<details>
<summary><strong>프라이버시는 어떻게 보호되나요?</strong></summary>

- ✅ 100% 로컬 데이터 저장
- ✅ 계정 불필요, 로그인 불필요
- ✅ 분석 없음, 추적 없음
- ✅ 오픈소스 코드 (감사 가능)
- ✅ 완전 오프라인 작동

</details>

<details>
<summary><strong>외관을 커스터마이징할 수 있나요?</strong></summary>

가능합니다! MiniCal은 다음을 제공합니다:
- 10개 이상의 내장 테마
- JSON 기반 커스텀 테마 (20개 이상 색상 파라미터)
- 레이아웃 커스터마이징 (크기, 주 시작일, 밀도)
- 모듈 전환 (표시 내용 선택)

자세한 내용은 [테마 가이드](THEMES.md)를 참조하세요.

</details>

<details>
<summary><strong>어떤 역법 시스템을 지원하나요?</strong></summary>

1. 양력 (전 세계 공통)
2. 음력 (중국 - 14억 사용자)
3. 이슬람력 (Hijri - 19억 사용자)
4. 히브리력 (유대교 - 1,500만 사용자)
5. 페르시아력 (Jalali - 1.2억 사용자)
6. 일본력 (레이와 연호 - 1.2억 사용자)
7. 불교력 (5억 사용자)

각각 네이티브 계산 엔진과 문화적 특징을 가지고 있습니다.

</details>
